# SQL Data Cleaning Project - Cleaning Project 1 

## Objective 
The objective of the project is to clean a messy orders dataset using SQL.

## Data Issues Identified 
- Duplicate records
- NULL emails 
- Invalid email formats 
- Extra space in customer names 
- City spelling mistakes
- Multiple date formats
- Missing dates 
- Negative orders amounts 

## Cleaning Steps

* Query 1 – Detect duplicates
* Query 2 – Remove duplicates
* Query 3 – Detect NULL emails
* Query 4 – Replace missing emails
* Query 5 – Detect invalid emails
* Query 6 – Fix invalid emails
* Query 7 – Trim customer name spaces
* Query 8 – Fix city spelling mistakes
* Query 9 – Trim city spaces
* Query 10–12 – Standardize date formats
* Query 13–14 – Handle missing dates
* Query 15 – Fix negative amounts
* Query 16 – Replace NULL amounts

## Final Step

Converted column data types to the correct SQL data types.
